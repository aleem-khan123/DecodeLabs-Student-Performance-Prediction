# Student Performance Analysis and Prediction

## Project Overview

This project was developed as part of the Decode Labs Data Science Internship.

The objective of this project is to analyze student academic performance and build a machine learning model capable of predicting exam scores based on academic and lifestyle factors.

The project follows the complete Data Science workflow including data understanding, data cleaning, exploratory data analysis, visualization, predictive modeling, and deployment through a Streamlit web application.

---

## Dataset Information

Dataset Name: Student Performance Dataset

Total Records: 10,000

Total Features: 8

Features:

* Study Hours
* Attendance
* Sleep Hours
* Internet Usage
* Assignments Completed
* Previous Score
* Exam Score
* Placement Status

Target Variable:

* Exam Score

## Model Performance

| Metric   | Value |
| -------- | ----- |
| MAE      | 6.92  |
| RMSE     | 8.79  |
| R² Score | 0.663 |

The model explains approximately 66.3% of the variation in student exam scores.
